\begin{frame}{Setup}
    \small
    \textbf{Goal.} Reproduce \emph{Yi \& Bhadani (2026), arXiv:2604.11831} for
    $n \in \{5,\dots,10\}$ qubits using the paper's recipe:
    \[
        \mathcal{L} = 1 - \tfrac{1}{n}\textstyle\sum_i \langle Z_i\rangle, \quad
        D = \lceil n^2 \log n\rceil, \quad
        \text{SGD}(lr = 0.1), \quad \text{max } 1500 \text{ iters},
        \quad \text{tol } 10^{-3}, \quad 5 \text{ seeds}.
    \]

    \textbf{Our stack.} Pure Python + Qulacs + NumPy; no TensorCircuit at runtime.
    Implementation written before the reference repo was consulted.
    TC$\leftrightarrow$Qulacs gate-equivalence test passes 9/9 cells.

    \textbf{This deck.} Side-by-side: \theirs{paper-reported number} vs \ours{our measured number}.
    Where they differ, we say so and explain why.
\end{frame}

\begin{frame}{Diagnosis — Why the Convergence Target Misses}
    \small
    \textbf{Paper Eq. (2):} $\hat O_{\mathrm{paper}} = I - \tfrac{1}{n_{\mathrm{data}}}\sum_i Z_i$ on the data register.

    \textbf{Reference repo} (\texttt{AARC-lab/DCAS\_2026\_QLINK} / \texttt{cost\_function.py}):
    \begin{itemize}\small
    \item Implements $1 - \tfrac{1}{n_{\mathrm{data}}}\sum_i P(q_i\!=\!|0\rangle)$ — i.e.\ exactly \emph{half} the paper's operator.
    \item Additional Q-LINK-specific bug: loop iterates $j \in [0, 2^{n_{\mathrm{data}}})$ over a $2^{n_{\mathrm{tot}}}$-length probability vector. In TC big-endian, this projects the first data qubit onto $|0\rangle$ and replaces it with the messenger in the measured set:
    \[
        \hat O_{\mathrm{buggy}} \;=\; I \;-\; \frac{1}{n_{\mathrm{data}}}\sum_{k=1}^{n_{\mathrm{tot}}-1} P_0^{(q_0)} P_0^{(q_k)}.
    \]
    \item Unit test \texttt{test\_buggy\_observable\_matches\_literal\_loop} pins this operator to the verbatim Python loop for $n_{\mathrm{tot}} \in \{3,4,5\}$.
    \end{itemize}

    \textbf{Effect on our numbers.}
    Running the paper's \emph{stated} cost is flat near the random-init state and SGD does not escape in 1500 iters. Running the \emph{buggy} operator (replication of authors' actual code) reproduces the published trajectory variances at the order-of-magnitude level (slide 4) but inflates Q-LINK(F) by the $P_0^{(q_0)}$ projector floor.
\end{frame}
